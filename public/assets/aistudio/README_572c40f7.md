# Тушканчики на старте — гонки по пустыне

Аркадная гонка верхом на тушканчиках. Вы — маленький наездник на длинноногом
тушканчике (по мотивам приложенного референса) — обгоняете трёх соперников
на дистанции 850 метров по вечерней пустыне.

![Гонка](preview/race.png)

## Запуск

Откройте `index.html` двойным щелчком. Игра полностью офлайновая: без сборки,
без интернета, без сервера.

Если нужно отправить игру одним файлом — используйте
`jerboa-race-standalone.html` (в нём уже лежат и код, и картинка).

## Управление

| Клавиши | Действие |
|---|---|
| **ПРОБЕЛ** / ↑ / W / клик по экрану | прыжок |
| **SHIFT** (удерживать) | спурт, пока есть силы |
| **P** / **ESC** | пауза |
| **M** | звук вкл/выкл |
| **R** | начать заново |

На телефоне: тап по экрану — прыжок, кнопка «СПУРТ» справа снизу — ускорение.

## Механика

- **Прыжок в такт.** Сразу после приземления жмите прыжок — получится
  «идеальный» прыжок и наполнится шкала **ПОТОК** (до ×5).
  Каждый уровень потока даёт **+4,5 %** к скорости.
- **Спурт** даёт **+28 %** скорости, но тратит шкалу **СИЛ**;
  силы восстанавливаются, когда вы не ускоряетесь.
- **Кактусы, камни и сухие кусты** нужно перепрыгивать. Столкновение —
  падение, потеря потока и скорости.
- Соперники подстраиваются по скорости, поэтому гонка остаётся плотной
  до самого финиша. Лучшее время сохраняется в браузере.

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | разметка страницы |
| `style.css` | оформление страницы и канваса |
| `jerboa.js` | векторный тушканчик и наездник, анимация прыжка |
| `game.js` | физика, трасса, соперники, HUD, звук, экраны |
| `assets/jerboa.png` | исходный референс (портрет в главном меню) |
| `tools/build-standalone.js` | сборка одностраничной версии |
| `preview/` | скриншоты игры |

## Сборка одного файла

```bash
node tools/build-standalone.js
```

Скрипт вставит CSS и JS внутрь HTML, а картинку превратит в `data:`-ссылку
и сохранит `jerboa-race-standalone.html`.

## Отладка

В игре есть служебные параметры в адресной строке:

- `?auto=1` — автопилот вместо игрока;
- `?seek=12` — прокрутить симуляцию на 12 секунд вперёд;
- `?freeze=1` — остановить время (удобно для скриншотов);
- `?debug=1` — строка с телеметрией.

Пример: `index.html?auto=1&seek=12&freeze=1`.
